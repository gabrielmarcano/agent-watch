# Agent Watch

Agent Watch lets you monitor and interact with AI development coding agents (Claude Code, Google Antigravity, OpenCode, and others) directly from your smartwatch.

The codebase is currently undergoing the Herdr-native refactor described in [`HERDR_REFACTOR_PLAN.md`](./HERDR_REFACTOR_PLAN.md).
Documentation and implementation guides are available in [`docs/`](./docs/).
