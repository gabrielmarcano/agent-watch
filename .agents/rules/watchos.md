# watchOS client rules (best-effort, simulator only)

> Applies to: watchos-app/**.

The app's state: `docs/STATUS.md`. While Phase 6 is open, its guide is `docs/phases/6-watchos.md`.

- **Best-effort.** It follows Wear OS: copy the UX already validated there (`wearos-app/ARCHITECTURE.md` §4–§4b); do not invent new behaviour here first.
- **No physical Apple Watch exists.** Report results as "verified in the simulator". Never claim device behaviour.
- **Swift 5.9+, SwiftUI, `NavigationStack`.**
- **Models mirror `pkg/model`** (`Codable`, `Identifiable`, `Sendable`). A contract change updates the Swift models too, so the app compiles (`schema-sync` skill).
- **Network:**
  - `/v1` over HTTPS;
  - the device token lives in the **Keychain**, not in `@AppStorage`;
  - SSE only while the scene is active, reconnected through an `AsyncSequence`.
- **Same command rules as Wear OS** (`wearos-app/ARCHITECTURE.md` §4): no raw keys, `answer`/`cancel` with `expected_seq` + `fingerprint`, and no auto-retry after 409.
- **No push code in the app:** alerts reach the Apple Watch through ntfy on the iPhone (`AGENTS.md` §1.6).
- **The project is generated by XcodeGen** (`project.yml`). Edit `project.yml`, then run `xcodegen generate`. Do not hand-edit `project.pbxproj`.

## Build

```bash
cd watchos-app
xcodegen generate
xcrun simctl list devices available | grep -i watch            # pick a watch simulator
xcodebuild -project AgentWatch.xcodeproj -scheme AgentWatch \
  -destination 'platform=watchOS Simulator,name=<simulator>' build
xcodebuild -project AgentWatch.xcodeproj -scheme AgentWatch \
  -destination 'platform=watchOS Simulator,name=<simulator>' test
```

`test` runs only if `project.yml` puts the test target in the scheme (`scheme: { testTargets: [...] }`).
