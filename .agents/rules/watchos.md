# watchOS client rules (best-effort, simulator only)

> Applies to: watchos-app/**.

Guide: `docs/phases/6-watchos.md`.

- **Best-effort.** It follows Wear OS: copy the UX already validated there; do not invent new behaviour here first.
- **No physical Apple Watch exists.** Report results as "verified in the simulator". Never claim device behaviour.
- **Swift 5.9+, SwiftUI, `NavigationStack`.**
- **Models mirror `pkg/model`** (`Codable`, `Identifiable`, `Sendable`). Even when the UI lags, a contract change must still update the Swift models so the app compiles (the app's current state: `docs/STATUS.md`).
- **Network:**
  - `/v1` over HTTPS;
  - the device token lives in the **Keychain**, not in `@AppStorage`;
  - SSE only while the scene is active, reconnected through an `AsyncSequence`.
- **Same command rules as Wear OS:** no raw keys, `answer`/`cancel` with `expected_seq` + `fingerprint`, and no auto-retry after 409.
- **No push code in the app:** alerts reach the Apple Watch through ntfy on the iPhone (`AGENTS.md` §1.6).
- **The project is generated by XcodeGen** (`project.yml`). Edit `project.yml`, then run `xcodegen generate`. Do not hand-edit `project.pbxproj`.
